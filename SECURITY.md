# Security Policy

## Supported Versions

This repository is architecture and ontology specification only (docs). No executable runtime.

## Reporting a Vulnerability

Please open a GitHub issue or contact via the portfolio governance: https://github.com/beyond-repair/ADL-Governance

Do not report security issues publicly until reviewed.

Claims remain capped per ADL-Governance CLAIM_VALIDATION.md. This is not a production host integrity product.
